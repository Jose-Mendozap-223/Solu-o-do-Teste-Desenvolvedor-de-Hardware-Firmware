# Resolvendo Teste Desenvolvedor-de-Hardware-Firmware
Neste repositório apresenta-se a resposta para o “Teste Situacional - Desenvolvedor de Hardware/Firmware” do candidato Jose Alfredo Mendoza Peñaloza, referente a um projeto de hardware embarcado para a detecção de um sinal externo e, a partir dele, acionar um motor por 10 segundos.

1. Apresentam-se os arquivos Gerber e Drill para visualização no visualizador de sua preferência.
2. Apresentação dos arquivos Pick and Place (PnP), que podem ser visualizados com um leitor de textos.
3. Apresentação do arquivo BOM, que pode ser visualizado com o software Excel.
4. Apresentação do esquema do circuito embarcado em PDF.
5. Apresentação do código em C do projeto para leitura do sinal externo e controle de motor DC, arquivo “Projeto_código.c”.
6. Apresenta-se o documento com as respostas do teste no arquivo: “Teste Situacional - Desenvolvedor de HardwareFirmware_Jose_Mendoza.docx”.
7. Por fim, apresentam-se os arquivos de desenvolvimento do projeto elaborados no KiCad, arquivos: “detetor de sinal 12v.kicad_pcb” e “detetor de sinal 12v.kicad_sch”.
